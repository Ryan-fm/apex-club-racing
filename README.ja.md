[![TITAN、6台のマシン、コース選択が並ぶAPEX CLUBのロビー](docs/images/lobby.jpg)](https://apex-club-racing.vercel.app/)

APEX CLUBは、ブラウザーで遊べる3Dアーケードレーシングゲームです。海沿いのロングコーナー、古都の城門、ネオンが輝く港を自分のマシンで駆け抜けましょう。ドリフトでチャージし、コーナーの出口のタイミングでブースト。小さな加速を、次の追い抜きにつなげます。

ゲームクライアントのダウンロードは不要です。ゲーム内の表示言語は英語と簡体字中国語に対応し、画面右上で切り替えられます。

## 3つのコース、3つの走り

**Bay Circuit — 海辺のサーキット**

海岸線と橋を駆け抜け、見通しのよいロングコーナーで走行ラインを探しましょう。海、島々、灯台を眺めながら3周を競います。

**Jade Citadel — 古都の城壁コース**

城門をくぐり、城壁に沿って遠くの山々へ。連続コーナーと高低差で、ドリフトとコーナー出口のブーストをつなぎます。

![Jade Citadelの3連続コーナー練習区間に立つTITANのゲーム画面](docs/images/citadel.jpg)

**Neon Harbor — ネオンの港**

ネオンのアーチを抜けて高架橋を上り、連続ヘアピン、埠頭のS字コーナー、低い位置の折り返し区間へ。中央のリング状ランドマーク、橋のケーブル、港のクレーンが深夜の街並みを彩ります。急コーナーでは早めに減速し、ドリフトのラインを組み立てましょう。

![Neon Harborのゲーム画面](docs/images/harbor.jpg)

*スクリーンショットは現在の開発版です。公開中のオンライン版とは、更新状況により画面や機能が異なる場合があります。*

## 自分のマシンを、自分のスタイルに

ガレージで左右にマシンを切り替え、カメラを回してボディを眺めながら、塗装、デカール、エキゾーストエフェクトを選べます。

![3Dプレビュー、マシン選択、塗装メニューを備えたTITANのガレージ画面](docs/images/garage.jpg)

| マシン | 走りの個性 |
| --- | --- |
| **COMET** | 軽快で扱いやすく、素早い方向転換が得意 |
| **APEX** | 速度と操作性のバランスがよく、初めてのレースにも最適 |
| **BOLT** | 最高速重視。コーナーへの進入は早めの準備が大切 |
| **SLIDE** | ドリフト特化で、チャージが速い |
| **TITAN** | 大径タイヤと露出したサスペンションが特徴のワイドトレッド装甲バギー |
| **VINTAGE** | クラシックな丸型ヘッドライトと軽快なスタート |

グロス、サテン、メタリックの塗装に、ツインストライプやチェッカー柄を組み合わせ、ジェットやパルスのエキゾーストエフェクトで仕上げましょう。カスタマイズは見た目のみを変更し、走行性能は変わりません。選択内容は使用中のブラウザーに保存されます。

## ソロで優勝を狙う。チームにポイントを持ち帰る。

- **ソロレース：** 7台のAIドライバーと3周のレースで優勝を争います。
- **4対4のチーム戦：** 自分と3台のAIチームメイトで、4台のAIライバルに挑戦。ゴール順位に応じてチームにポイントが入ります。
- **練習：** ドライビングレッスンでステアリング、ブレーキ、ドリフト、ミニブーストを覚えましょう。現在の開発版には、城門の3連続コーナーチャレンジもあります。

EMPで近くのライバルを妨害し、追い抜く隙を作れます。チーム戦では味方に当たりません。自己ベスト更新、パーソナルゴーストとの勝負、銅・銀・金のチャレンジメダルにも挑戦できます。

*現在はAIと競うシングルプレイです。オンラインマルチプレイには対応していません。*

## 最初の1周は、ここから

マシンとコースを選び、**Launch race**をクリック。初めてならドライビングレッスンから始められます。

初期設定では自動アクセルが有効なので、ステアリングとブレーキに集中できます。まずは、**Shiftを押しながら方向キーでドリフト → チャージ後にShiftを離す → Wでミニブースト**を練習しましょう。ドリフトを解除するだけではブーストは発動しません。

| 初期キー設定 | 操作 |
| --- | --- |
| **← / →** | 左右にステアリング |
| **↑ / ↓** | アクセル / ブレーキ。停止後も↓を押し続けると後退 |
| **Shift + 方向キー** | ドリフト。カウンターステア中もShiftを押し続ける |
| **W** | 発動可能なミニブースト、空中ブースト、着地ブーストを使用 |
| **Ctrl** | ニトロを使用 |
| **Q** | EMPを発動 |
| **H / Esc** | 一時停止、操作説明の確認、コースへの復帰 |
| **R** | レースを最初からやり直す |

キーは**Settings → Custom hotkeys**で変更できます。基本に慣れたら、カウンターステアによるカットブースト、空中ブースト、着地ブーストをつないでみましょう。

**スマートフォン：** 横画面がおすすめです。画面上の方向、ドリフト、ミニブースト、ニトロ、ブレーキ、アクセル、EMPボタンで操作できます。対応端末では、スマートフォン操作設定から傾き操作も有効にできます。タッチの方向ボタンが常に優先されます。センサーの許可や全画面表示への対応は、端末とブラウザーによって異なります。

**自分のペースで：** 設定では初心者アシスト、カメラの動きを抑えるオプション、画質、音量を調整できます。動けなくなったらブレーキで停止して後退するか、一時停止してコースへの復帰を選んでください。

APEX CLUB은 브라우저에서 바로 즐기는 3D 아케이드 레이싱 게임입니다. 나만의 카트로 해안의 긴 코너, 고성의 성문, 네온빛 항구를 달려 보세요. 드리프트로 게이지를 채우고 코너 탈출, 점프, 착지 타이밍에 부스트를 사용해 다음 추월로 이어 가세요.

게임 클라이언트를 내려받을 필요가 없습니다. 게임 화면은 영어와 중국어 간체를 지원하며, 오른쪽 위에서 언어를 바꿀 수 있습니다.

## 세 개의 트랙, 서로 다른 리듬

**Bay Circuit — 해안 서킷**

해안과 다리를 따라 가속하고, 넓고 긴 코너에서 나만의 주행 라인을 찾아보세요. 바다, 섬, 등대가 펼쳐진 풍경 속에서 세 바퀴를 겨룹니다.

**Jade Citadel — 고성의 성벽길**

성문을 지나 성벽을 따라 먼 산을 향해 달립니다. 연속 코너, 높낮이 변화, 황금색 점프대에서 드리프트와 점프를 연결해 보세요.

![Jade Citadel의 세 코너 연습 구간에 있는 TITAN 게임 화면](docs/images/citadel.jpg)

**Neon Harbor — 네온 항구**

네온 아치를 지나 고가교 정상으로 올라간 뒤, 연속 헤어핀과 부두의 S자 코너, 낮은 회차 구간을 공략하세요. 중앙의 고리형 랜드마크, 교량 케이블, 항만 크레인이 한밤의 스카이라인을 만듭니다. 급커브에서는 미리 속도를 줄이고 드리프트 라인을 계획해야 합니다.

![Neon Harbor 게임 화면](docs/images/harbor.jpg)

*스크린샷은 현재 개발 버전입니다. 온라인 버전의 화면과 기능은 업데이트 상황에 따라 다를 수 있습니다.*

## 나만의 카트, 나만의 스타일

차고에서 좌우로 카트를 바꾸고, 카메라를 돌려 차체를 살펴보세요. 도장, 데칼, 배기 이펙트도 직접 고를 수 있습니다.

![3D 미리보기, 카트 선택, 도장 옵션을 갖춘 APEX CLUB의 TITAN 차고](docs/images/garage.jpg)

| 카트 | 주행 특징 |
| --- | --- |
| **COMET** | 가볍고 민첩해 빠른 방향 전환에 강함 |
| **APEX** | 속도와 조작성이 균형 잡혀 첫 레이스에 적합 |
| **BOLT** | 최고 속도 중심. 코너 진입을 미리 준비해야 하는 카트 |
| **SLIDE** | 드리프트 특화로 게이지를 더 빠르게 충전 |
| **TITAN** | 넓은 윤거, 대형 타이어, 노출된 서스펜션의 장갑 버기 |
| **VINTAGE** | 클래식한 원형 헤드라이트와 경쾌한 출발 |

유광, 새틴, 메탈릭 도장에 두 줄 스트라이프나 체크무늬를 조합하고, 제트 또는 펄스 배기 이펙트로 마무리하세요. 꾸미기는 외형만 바꾸며 카트의 주행 성능에는 영향을 주지 않습니다. 선택한 설정은 현재 브라우저에 저장되어 다음에도 사용할 수 있습니다.

## 혼자 우승을 노리거나, 팀을 위해 점수를 쌓거나

- **개인전:** AI 드라이버 일곱 명과 세 바퀴 동안 우승을 겨룹니다.
- **4대4 팀전:** 플레이어와 AI 팀원 세 명이 AI 상대 네 명에게 도전합니다. 완주 순위에 따라 팀 점수를 얻습니다.
- **연습:** 주행 튜토리얼에서 방향 조작, 제동, 드리프트, 미니 부스트를 익혀보세요. 현재 개발 버전에는 별도의 성문 세 코너 챌린지도 있습니다.

EMP로 가까운 상대를 방해해 추월할 틈을 만들 수 있습니다. 팀전에서는 아군에게 피해를 주지 않습니다. 개인 최고 랩타임을 갱신하고, 자신의 고스트와 겨루고, 동·은·금 챌린지 메달에 도전해 보세요.

*현재는 AI와 함께 달리는 싱글 플레이 게임입니다. 온라인 멀티플레이는 지원하지 않습니다.*

## 첫 바퀴는 여기서 시작하세요

카트와 트랙을 고른 뒤 **Launch race**를 누르세요. 처음이라면 주행 튜토리얼부터 시작할 수 있습니다.

기본적으로 자동 가속이 켜져 있으므로 방향 조작과 제동에 집중하면 됩니다. 먼저 **Shift를 누른 채 방향키로 드리프트 → 게이지를 채운 뒤 Shift에서 손 떼기 → W로 미니 부스트** 순서를 연습해 보세요. 드리프트를 해제하는 것만으로 부스트가 자동 발동하지는 않습니다.

| 기본 키 | 조작 |
| --- | --- |
| **← / →** | 좌우 방향 조작 |
| **↑ / ↓** | 가속 / 제동. 정지한 뒤에도 ↓를 누르고 있으면 후진 |
| **Shift + 방향키** | 드리프트. 반대 방향으로 조향할 때도 Shift를 유지 |
| **W** | 사용 가능한 미니 부스트, 공중 부스트, 착지 부스트 발동 |
| **Ctrl** | 니트로 사용 |
| **Q** | EMP 발동 |
| **H / Esc** | 일시 정지, 조작 설명 확인, 카트를 트랙으로 복귀 |
| **R** | 레이스 다시 시작 |

키는 **Settings → Custom hotkeys**에서 바꿀 수 있습니다. 기본 조작에 익숙해지면 반대 조향을 활용한 컷 부스트, 공중 부스트, 착지 부스트를 연속으로 연결해 보세요.

**휴대폰 플레이:** 가로 화면을 권장합니다. 화면의 방향, 드리프트, 미니 부스트, 니트로, 브레이크, 가속, EMP 버튼을 사용하세요. 지원 기기에서는 휴대폰 조작 설정에서 기울기 조향도 켤 수 있으며, 터치 방향 버튼이 항상 우선합니다. 센서 권한과 전체 화면 지원 여부는 기기와 브라우저에 따라 다릅니다.

**자신의 페이스에 맞게:** 설정에서 초보자 보조 기능, 카메라 움직임 줄이기, 화질, 음량을 조절할 수 있습니다. 움직이지 못할 때는 브레이크로 멈춘 뒤 후진하거나, 일시 정지 후 트랙 복귀를 선택하세요.

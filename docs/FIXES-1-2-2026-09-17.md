### 1. 可靠性与阶段 A

- 原始帧间隔独立于物理追帧上限：180ms 输入记录为 180ms，而模拟仅推进 80ms。报告明确记录被截去的模拟时间。
- 只统计比赛帧；大厅、倒计时、暂停以及恢复的边界帧不混入。每次开始清空当前样本。面板每 500ms 汇总，不在样本填满后退化成每帧排序和写 DOM。
- JSON 包含原始帧、各 CPU 阶段、模拟子步、renderer calls/triangles、构建、分辨率、语言及输入轨迹 ID。GPU 时间为 null，不把 CPU 提交时长当作 GPU 耗时。
- 城门练习使用 `apex-challenge-citadel-gates-v1-*`，独立结算；不写正式圈速、幽灵车或奖牌。规则层同时拒绝从赛道中途开始的首个不完整圈。
- 删除翻译子串反向替换；按键说明保存英文原文并按当前语言和绑定渲染。修复中文冷启动回英文、改键后提示、车库前后选车辅助标签。
- 玩家驾驶步独立为 `runtime/player-simulation.js`。玩家与 AI 模型姿态/车轮每显示帧更新一次；教学连续提示也移到显示帧。物理子步中仍有离散事件通知与教学流程协调，不宣称整个 game.js 已全面模块化。

### 2. 三弯驾驶段

- 三处弯道、跳台和独立终点，阶段提示使用用户实际键位；结果展示漂移、小喷、脱喷、飞喷、落地喷、碰撞次数。
- 补足起漂 → 蓄力 → 反打/松漂移 → 手动小喷 → 飞喷/落地喷的固定输入回放。只有显式 `?perf=1&replay=gate` 启用回放，普通比赛不会自动转向。
- 小喷增加 100ms 单次输入缓冲，仅等待真实触发窗口；撞墙清空窗口。没有改变车辆转向、速度、漂移蓄力阈值或正式比赛规则。
- 加速 HUD 标明实际喷射类型；脱喷、飞喷、落地喷使用不同提示音。加入仅影响画面的落地悬挂回弹，以及最多约 5.7° 的跟随镜头方向平滑，不向物理转向写回。减少镜头运动选项禁用回弹。
- 在生产驾驶函数中测试撞墙取消喷射、刹车倒车、转向脱困，覆盖 30/60/120Hz。

# 弯道近道与快速路

三张赛道均保留原主路，新增两条近道、两条快速路。绿色路面箭头与地图线表示近道，青色表示快速路。入口标牌注明道路类型；分流和回流区域移除原有护栏。

- 近道宽 44 个世界单位，比主路窄，连接同一弯道前后的主路。晴湾的切弯较温和，玉城与霓虹港湾的近道节省更多路程；入弯及回流仍需要玩家转向。
- 快速路宽 50 个世界单位，中段加速带将目标极速提高 25%，加速响应提高 80%。不消耗氮气，不与氮气极速倍率叠乘；刹车和倒车仍优先。
- 道路均保持地面竞速，没有跳板。所有支路都不跨越起终点线。支路进度映射到对应主路区间，三圈完赛规则保持一致。
- 单人玩家、四人房服务端与客户端预测共用同一道路投影和加速判定。单人 AI 继续沿主路行驶。
- 小地图绘制支路；玩家及联机对手使用真实世界坐标。新路线使用独立的本地最佳圈和幽灵车记录键，旧记录保留。
- 三连弯练习及驾驶教学仍使用原主路判定。

`tests/track-routes.test.mjs` 验证每条支路的通行和回流、连续比赛进度、道路坡度及曲率、加速带刹车优先、车辆恢复，以及联机预测与服务端结果的一致性。测试控制器仅存在于测试文件，不参与玩家转向。

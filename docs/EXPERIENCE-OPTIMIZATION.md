# 开赛与手机体验优化

日期：2026-10-30。通用修改在 `main`；不涉及 Toy SDK 或发布。

## 玩家体验

- “开始比赛”始终进入比赛，不再根据本机教学标记把首次点击转入教学。独立的“驾驶练习 · 可选教学”入口保留原来的转向、刹车、漂移和小喷练习。
- 倒计时前准备当前赛车、AI、追车镜头遮挡索引、材质和实际渲染输出。准备时冻结比赛与挑战计时，完成后再倒计时。练习与正式比赛使用不同缓存；返回大厅会取消旧请求，同配置重开复用准备结果。
- 手机挑战 HUD 平时只显示单行目标进度，取得新的目标进展时展开 2.6 秒。连段倒计时衰减、重复进入同一近道、名次来回变化不会持续触发展开；暂停冻结提示计时。
- 设置 → 操控 → 手机操控增加转向手、按键大小和边距选择。支持左右互换、85/100/115% 大小与三档边距，自动保存到本机，可恢复默认；存储不可用时只在本次会话生效。
- 横屏底部固定保留开始比赛、驾驶练习、好友同玩三个动作；竖屏入口为滚动内容预留底部空间。诊断面板文字不再拦截后方教学按钮。

## 渲染优化

AI 赛车仅在相同父节点内按完全相同的材质与渲染属性合并静态部件。车轮转向和旋转、尾焰、驾驶员与套件显隐继续使用原有层级；车队颜色继续使用原材质。玩家赛车及车库改装保留原有独立部件。

七位 AI 的可见网格由 1091 降至 385，减少约 65%。变更车型前恢复原部件，只释放合并产生的新几何；普通重开和返回大厅不重复构建相同车型。

同一台开发机、1440×900、DPR 1、高画质、APEX、幽光南瓜谷、八辆赛车、静止倒计时网格的两次采样：

| 指标 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 渲染调用（包含阴影与后处理） | 1598 | 806 |
| 已上传几何数量 | 1366 | 660 |
| 渲染提交三角形 | 586804 | 589704 |

渲染调用减少约 50%。模型几何测试确认合并前后顶点、三角形、材质与包围盒一致；提交三角形的小幅差异来自合并后的剔除粒度。减少调用数不代表 FPS 成倍提升，真机表现仍取决于设备。

一次准备流程样本约 206ms；练习→正式比赛→重开的独立流程样本分别为 628.6ms、51.9ms 和缓存复用 5.2ms。此时间在比赛计时之外，首次准备仍有成本；不承诺所有浏览器完全消除卡顿。

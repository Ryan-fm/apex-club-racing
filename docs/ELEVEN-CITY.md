# 十一城：端游实机参考重建

本地入口：`http://127.0.0.1:8080/dist/race.html?scene=eleven`。运行 `npm run build` 和 `npm start` 后打开；也可以在比赛大厅选择第五张赛道卡片。

## 实现与参考

使用项目已有的本地 Three.js 渲染器，新增 `eleven-layout.js` 和 `eleven-city.js`。依据以下端游实机画面重建平地城市赛道，不使用手游重制版作为造型基准：

- [飞车端游地图教学：十一城](https://www.bilibili.com/video/BV1Qc41187Fw/)
- [QQ 飞车系列：十一城](https://www.bilibili.com/video/BV1oN4y1g7LT/)
- [端游十一城竞速实机](https://www.bilibili.com/video/BV11U4y1h7Dx/)

道路为闭合的连续回头弯与后街折线，包含四处街角近道。所有近道与主路共享车辆投影、圈数进度和服务端模拟；没有给该城市地图添加快速路加速带。阶梯路沿、门楼、玻璃楼群、圆顶建筑、花坛、树木、街灯、铁栏、转弯圆牌、箭头和天空使用项目自行编写的几何体；玻璃窗、树叶和指示牌使用 Canvas 纹理。低处路沿采用连续扫掠截面，近道交汇面采用深度偏移，避免弯道拼缝与重叠闪烁。

真实感优化加入了 Poly Haven 的 CC0 摄影材质，用于沥青、混凝土、铺地、草地与树皮，具有颜色、法线和粗糙度贴图；天空使用摄影 HDR 全景。纹理沿世界坐标投影，避免随着路沿和建筑实例尺寸拉伸；颜色按明亮城市配色进行调整。玻璃反射使用一次离屏捕获的城市环境，不在每帧重拍。照片来源、作者和文件哈希见 [材质说明](../assets/city/LICENSE.md) 与 `assets/city/provenance.json`；授权说明见 [Poly Haven 官方许可](https://polyhaven.com/license)。15 张 1K 表面贴图压缩后总计约 5.05 MiB，HDR 天空约 1.37 MiB，全部随构建包本地加载。

沿街增加连续铺地、建筑入口、雨棚、台阶和周围街区，楼群包含矩形、圆柱和石材立柱造型。树木使用渐细枝干和有透明空隙的叶片簇替代实心球冠，降低树冠几何量；地面接触阴影与跟随车辆的日光阴影补足近景层次。暂停时窗口缩放也会重新渲染，避免横屏切换后画面空白。

这是可玩的参考重建版，**不是原版模型、纹理与坐标的逐项还原**。街区间距、楼高、转弯半径和装饰位置依据视频估算，仍与原版存在差异。驾驶手感、赛车和三圈比赛规则沿用 APEX CLUB；当前不宣称与 QQ 飞车的物理或竞赛规则一致。

## 接入范围

- 第五张赛道卡片、中文名称、实时地图、场景切换缓存和车库返回入口。
- 单人 AI 比赛和服务端强制限制最多四人的好友房。
- 本地最佳单圈与幽灵车独立存储。现有云端成绩库只支持原来的地图；十一城完赛不会提交到该库。
- 城市镜头使用较近的跟随距离，仍经过每帧中心与两侧遮挡探测。其他地图保留原有镜头参数。
- 所有通用功能在 `main` 开发，没有接入 Toy SDK。

## 验证与截图

新增自动检查覆盖平地闭环、非相邻道路间距、完整一圈、四处近道、进度连续性和四人房限制；场景缓存测试包含与其他地图反复切换。全套检查结果为 142 项、140 通过、2 跳过；跳过项需要外部 Redis 服务。

截图由本地浏览器中的实际 WebGL 游戏捕获，固定车辆位置以便比较，没有使用图片生成替代渲染。图片和端游参考资料保存于忽略目录 `output/eleven-city/`，不进入发布包。`start.png`、`start-wide.png`、`downtown.png`、`rear-cuts.png` 和 `aerial.png` 分别展示驾驶、门楼、城市直道、近道交汇与整体布局。浏览器截图不能证明真实移动设备的帧率。

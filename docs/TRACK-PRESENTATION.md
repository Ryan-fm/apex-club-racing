# 赛道质感与捷径镜头

通用改动在 main 开发，Toy 分支只同步通用提交。

- 镜头沿实际车头方向跟随，不提供辅助转向。主路/分支坡面的 up 向量平滑过渡。
- 使用赛车上方的视线锚点探测道路、护栏、岩石等实体。遇遮挡收短镜头，离开遮挡后缓慢恢复；不参与车辆碰撞或联网状态。
- 避障每秒探测 20 次，缓存静态网格，过滤隐藏地图与透明特效。地图切换后重置镜头；新建缓存道路更新碰撞候选。
- 四张赛道共用沥青细节、实体路肩、边缘反光标记及外弯方向牌。主路分岔开口取消横穿捷径的路肩色块和车道标线。
- 分支有厚度、护栏立柱、连续导向箭头、侧置入口牌和回流牌。快速路保留蓝色加速带。地图布局、近道长度、物理、进度与榜单规则不变。
- 峡谷桥面改为薄石材路基与支柱，岩层改为贴合岩体的形状，避免方形板块突出。

验证：驾驶/多人回归测试、镜头遮挡/恢复/坡面过渡/缓存切换测试；浏览器检查四张地图 16 条支路各入口、中段、出口共 48 个取景点，以及 844×390 横屏出口画面。浏览器取景使用临时测试注入，不包含在发布文件中。尚未在小米真机上验证性能或完整的人手驾驶过程。

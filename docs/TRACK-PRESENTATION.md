# 赛道质感与捷径镜头

通用改动在 main 开发，Toy 分支只同步通用提交。

- 镜头沿实际车头方向跟随，不提供辅助转向。主路/分支坡面的 up 向量平滑过渡。
- 使用赛车上方的视线锚点探测道路、护栏、岩石等实体。遇遮挡收短镜头，离开遮挡后缓慢恢复；不参与车辆碰撞或联网状态。
- 避障每帧探测镜头中心及左右边缘，使用静态空间索引只检测附近网格与实例，过滤隐藏地图、透明特效及路面标记。地图切换后重置镜头；新建缓存道路更新碰撞候选。
- 四张赛道共用沥青细节、实体路肩、边缘反光标记及外弯方向牌。主路分岔开口取消横穿捷径的路肩色块和车道标线。
- 分支有厚度、护栏立柱、连续导向箭头、侧置入口牌和回流牌。快速路保留蓝色加速带。
- 峡谷桥面改为薄石材路基与支柱，岩层改为贴合岩体的形状，避免方形板块突出。

验证：驾驶/多人回归测试、镜头遮挡/恢复/坡面过渡/缓存切换测试；浏览器检查四张地图 16 条支路各入口、中段、出口共 48 个取景点，以及 844×390 横屏出口画面。浏览器取景使用临时测试注入，不包含在发布文件中。尚未在小米真机上验证性能或完整的人手驾驶过程。

## 近道的三段设计

参考 [QQ 飞车十一城近道攻略](https://shouyou.gamersky.com/gl/201803/1021619.shtml?tag=wap) 中通过路旁标记判断入弯点、连续近道需要控制漂移路线的玩法，再结合本作地图设计：

- 每张图一条顺弯内线和一条精准切弯，核心半宽分别 21 / 18，入口用 smoothstep 收窄，出口用更长的扇形过渡放宽。保持真实车头驾驶，不自动对准捷径。
- 晴湾进阶路线从 .41–.56 改为 .38–.65，跨过完整弯段，路程收益从约 4% 提升至约 10%。不保证比赛用时一定下降，入线和碰撞会影响收益。
- 提前约 110 个世界单位设置分岔方向牌；入口导向标记、窄路入口立柱、侧置路线牌给出入线参照。提示牌有立柱且放在道路之外，不用横跨车道的门头。
- 中段提示为几何路程收益百分比；出口放宽与主路相接，保留上一轮的避障镜头。开口的主路仍可直接通过。
- 晴湾装饰岛屿为可选道路预留净空；快速路几何和加速机制保持原规则，主路布局和多人进度算法保持原规则。

验证：八条近道的几何/坡度/避开其他道路检查、服务端测试驾驶全程回流、入口出口宽度连续性；四图八近道 24 个静态取景点及横屏出口画面。图形验收仍使用临时取景注入，没有加入发布代码。

## 2026-10-13 快速路连续驾驶与路面表现

复现了玉城第一条快速路穿过城门及侧楼、港湾支路穿过桥塔的情况：原镜头收缩比例最低到 0，相邻取景的相对镜头跳动约 70 单位。连续物理驾驶还发现港湾第二条快速路回流时会碰到标牌支柱；支柱在支路之外，但位于主路之内。

- 玉城分岔处的侧楼移到更远位置，分岔区移除跨路城门及灯笼支架。港湾桥塔、路灯、方向牌避开分岔；仓库与货场平台同时检查主路与支路净空。
- 分支标牌及支柱为整个道路并集留出余量，避免出弯时侵入主路。
- 镜头改为每帧三条探测线。静态实例按 96 单位网格建立索引，不对整批数千实例逐一 raycast；真实墙体仍立即收短镜头，离开后逐渐恢复。
- 快速路横向偏移采用两端一、二阶导数为零的曲线，最大偏移缩减 10%，第一条快速路及晴湾第二条延长分流/回流区。宽度平滑收窄和放宽；分支姿态插值相邻切线，入口与出口匹配主路方向。单人、多人服务端与预测仍共用道路几何。
- three.js 0.179.1 已在本地提供 WebGL、物理材质、阴影与泛光。本轮继续使用该渲染链：增加共享的 128×128 法线纹理、细微粗糙度变化、道路侧面厚度和低强度发光标记；远处细节做导数过滤，回流内部移除露出的支路裙边。重叠顶面按主路高度衔接，道路顶面只接收阴影，侧面保留投影，减少自阴影条纹。无新增远程资产或运行依赖。
- 路线变化后，本地最佳圈与幽灵记录使用 `roads-v2` 键；旧 `hills-v1` 数据保留，三连弯挑战记录规则保持原样。

验证：完整测试 138 项，136 通过，2 项需外部 Redis 的集成测试跳过；真实四人 WebSocket 测试通过。构建与 `git diff --check` 通过。

浏览器使用临时注入（不进入构建），检查四图 16 条支路、每条左/中/右三条取景线，以及每条入口/中段/出口的 48 张桌面截图和 4 张 844×390 横屏截图。进一步用生产驾驶物理、真实车头方向和生产镜头连续驶过 16 条支路并回流：最小跟车距离 68.30，最大相对镜头变化 2.20；没有再出现镜头缩到车顶的情况。测试控制器有少量擦墙，仍需人工转向，未向游戏加入自动驾驶。

证据保存在本地忽略目录 `output/playwright/road-optimization/`，其中 `driving-report.json` 为连续驾驶结果。浏览器无 WebGL/着色器错误。横屏检查使用桌面浏览器调整视口，未完成手机真机性能测试或人工全程驾驶。

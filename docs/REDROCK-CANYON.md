# 赤岩峡谷 / Redrock Canyon

第四条通用赛道，ID `canyon`。暖色砂岩、落日远山、仙人掌和三座跨道岩拱构成独立场景；场景静态批量实例化，没有逐物体动画或额外灯光。主路闭合且没有 XZ 交叉，使用共享 0.55 样条张力；客户端和房间服务使用同一组控制点、坡度与支路数据。

两条近道连接主路 10%→22%、43%→54% 的弯道区间；两条快速路位于 1.5%→7%、85%→92%，加速带不消耗氮气。主路保留 38 单位半宽，坡道为贴地连续起伏，没有增加跳板。景观岩石和仙人掌避开主路及所有支路，支路汇合处护栏开口。

接入内容：选赛道卡片和预览、驾驶 HUD / 小地图、个人纪录与幽灵、生涯挑战、四人房选择与服务端校验、车库返回链接、独立全球榜赛道筛选。首页总赛道数改为四条。其他赛道的历史纪录不清除。

发布正式版前，需要应用 `supabase/migrations/202610100001_canyon.sql`，扩展整场成绩表约束与提交 RPC；本次只保存迁移文件，没有修改生产数据库。Toy 专属分支使用榜单 4，与原有榜单 1、2、3 分离。平台接入不进入 main。
